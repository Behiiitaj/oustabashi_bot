# ربات پیگیری تسک‌ها

## راه‌اندازی

1. MongoDB را اجرا کنید.
2. از روی `.env.example` یک فایل `.env` بسازید.
3. توکن جدید ربات بله را در `BOT_TOKEN` قرار دهید.
4. برای به‌دست‌آوردن شناسه مدیر، ربات را اجرا کنید و `/myid` بفرستید؛ عدد نمایش‌داده‌شده را در `ADMIN_ID` قرار دهید.
5. برنامه را اجرا کنید:

```bash
npm start
```

در شروع برنامه، افراد و تسک‌ها از `tasks.docx` به‌صورت امن در MongoDB ثبت یا به‌روزرسانی می‌شوند؛ سابقه‌های ثبت‌شده حذف نمی‌شوند.

برای گزارش PDF، برنامه از Python محیط داخلی PDF استفاده می‌کند. اگر مسیر Python در سیستم شما متفاوت است، مقدار `PDF_PYTHON` را در `.env` تنظیم کنید.

## فرمان‌ها

- `/start` یا `/menu`: منوی اصلی
- `/check`: بررسی تسک‌های امروز
- `/check 2026-09-09`: بررسی تسک‌های یک تاریخ مشخص
- `/report`: گزارش امروز
- `/report 2026-09-09`: گزارش یک تاریخ مشخص
- `/myid`: نمایش شناسه کاربر
برای سه مدیر، شناسه‌ها را در متغیر `ADMIN_IDS` و با کاما جدا کنید؛ برای نمونه: `ADMIN_IDS=1327301762,123456789,987654321`
